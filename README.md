# Java Product Sales Report

A Java console application that generates a product sales report using 2D arrays.

## What it does
- Displays sales in a formatted table using printf
- Calculates Total Sales
- Calculates Average Sales
- Finds Maximum and Minimum Sale

## Technologies
- Java
- JUnit 5
- IntelliJ IDEA

## How to run
1. Open in IntelliJ
2. Run Main.java
3. Run ProductSalesTest.java to see tests pass

## Example Output
YEAR 1  300  150  700
YEAR 2  250  200  600
Total sales: 2200
Average sales: 367
Maximum sale: 700
Minimum sale: 150
